# Status-Code:--
1) 200 -- > OK { The request succeeded.
                Ex:- Fetching all  users.}
2) 201 -- > Created { A new resource was successfully     created. 
                Ex:-Creating a product.}
3) 400 -- > Bad Request { The client send invalid or incomplete data.
                Ex:-Missing product name.}
4) 404 -- > Not Found { The requested resource doesnot exist.}
                Ex:-user ID 99 isnot found.
5) 500 -- > Internal Server Error { THe server encountered an unexpected problem.}
                Ex:-an unhandled server-side error.
